# Dominus Licett Agent

Instalador del agente de monitoreo de productividad empresarial.

## Descarga

Descarga la ultima version del instalador desde la seccion [Releases](https://github.com/JhonGris/DominusLicett-Agent/releases).

## Requisitos

- Windows 10 o superior (64-bit)
- 500 MB de espacio en disco
- Permisos de administrador
- Conexion a internet

## Instalacion

1. Descargar `DominusLicettAgent.msi`
2. Ejecutar como administrador
3. Ingresar el codigo de activacion proporcionado por email

## Instalacion silenciosa

```powershell
msiexec /i DominusLicettAgent.msi CODE=TU_CODIGO /qn
```
